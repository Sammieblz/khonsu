# Khonsu video walkthrough

Local Remotion project for Samuel's narrated feature walkthrough and the NASA
Space Apps submission cut. Production application packages are unchanged.

## Exports

Files are written into `out/`:

- `Khonsu-Submission-30s-1080p.mp4`: the submission demo, exactly 900 frames at
  30 fps, with English narration and burned-in subtitles.
- `Khonsu-Full-Walkthrough-1080p.mp4`: detailed 4 minute 28.9 second tutorial.
- `khonsu-short.srt` and `khonsu-long.srt`: separate synchronized subtitle tracks.

Use the short cut for the required demo. The longer tutorial is supplementary.
Neither file has been uploaded to the submission portal.

## Requirements checked

The actual two-page `Judging Criteria.pdf` supplied by Samuel was visually read,
including the image-only text. Page 1 specifies a maximum 30-second video or a
seven-slide presentation, English materials (English subtitles for other spoken
languages), resource attribution and a November 15, 2026 11:59 p.m. local deadline.
This resolves the earlier pasted-text OCR ambiguities about slide count and time.
The five judging criteria on page 2 are impact, creativity, validity, relevance
and presentation. Event registration and portal submission remain separate tasks.

The short cut covers the human benefit, Khonsu's story, real SPHEREx use, actual
date comparison, evidence saving and the distinction between estimated patches
and measurements. The long cut demonstrates each control group and notebook
workflow, with source/quality limitations in the narration.

## Rebuild locally

From this directory:

```powershell
npm ci
npm run studio -- --port=3100
```

The compositions are `KhonsuSubmission` and `KhonsuWalkthrough`. The project
uses Remotion 4.0.543, React 19.2.0 and a local Chrome executable. No cloud
rendering or paid service was provisioned.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/narrate.ps1
python scripts/prepare.py
npx remotion render src/index.tsx KhonsuSubmission out/Khonsu-Submission-30s-1080p.mp4 --codec=h264 --crf=18 --audio-codec=aac --concurrency=3 --browser-executable="C:/Program Files/Google/Chrome/Application/chrome.exe"
npx remotion render src/index.tsx KhonsuWalkthrough out/Khonsu-Full-Walkthrough-1080p.mp4 --codec=h264 --crf=18 --audio-codec=aac --concurrency=4 --browser-executable="C:/Program Files/Google/Chrome/Application/chrome.exe"
python scripts/finalize.py
```

The finalizer checks resolution, frame count, codecs and duration, and writes
`out/verification.json` with checksums. AAC encoder padding can otherwise make
the 30-second composition's container slightly longer than 30 seconds. The
finalizer removes that padding without cutting speech or re-encoding video.
Open `out/OPEN-VIDEOS.html` to play both delivered videos locally. The output
folder also contains `Khonsu-Transcript.txt` and separate subtitle files.

Narration uses the installed Windows Microsoft Zira Desktop voice through
System.Speech. Each sentence is synthesized separately, then timed from its WAV
sample count. The detailed cut plays at 1.04x and the short cut at 1.22x. Caption
boundaries follow those audio durations. `prepare.py` needs NumPy for the original
quiet ambience; it does not modify scientific images.

`scripts/capture.mjs` records the running local app at port 3000 using Playwright
from the existing `.cache/browser-tools` installation. It uses isolated browser
contexts, never the visitor's own notebook. Delete `captures.json` only when you
intend to re-record all clips. Existing entries are otherwise resumed. Footage
and WAV assets remain in `public/captures/` and `public/narration/` locally; large
media and final renders are ignored by Git.

## Content and edits

`script.json` is the editable narrative. `src/timeline.json` and SRTs are
generated by `scripts/prepare.py`. `captures.json` records the real-video trim
points. The Remotion composition adds original star arcs, title reveals,
chapter cards, fades, a progress line and legible captions. A small rectangle
covers the local Next.js development badge in unused interface space; it never
covers a scientific pixel. Recorded observation images are not retouched.

See [CREDITS.md](CREDITS.md) for sources and the reference text to carry into the
submission. The editable project and exports are local delivery artifacts.
