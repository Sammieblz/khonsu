# Khonsu v0.1.0: Space Apps public preview

Khonsu is a browser observatory for exploring real SPHEREx infrared observations
across their actual dates. This release brings together the dedicated console,
image display improvements, guided exploration and durable local notebooks.

## Included

- Dedicated, screen-fitting console with grouped Field, Display, Layers,
  Compare, Notes and Info controls.
- Three-second Khonsu entry animation with Skip, Cancel and reduced-motion
  support. Later data loads show ordinary progress feedback.
- Seven-step Guided Mode and a comprehensive static `/docs/` field guide.
- Observation notes without marking a pixel, plus candidate notes that retain
  coordinates, original validity, timestamps and source provenance. Edit,
  delete and export both kinds of notes.
- Private SQLite notebook backups in local Docker, browser fallback, legacy
  migration, offline retry and explicit resolution of conflicting tab edits.
- Responsive time-arc dragging and a short spring release onto real observation
  dates. Keyboard and reduced-motion selection remain immediate.
- Clean View estimates for eligible gaps, original-image comparison, quality
  inspection, optional display refinement and bounded high-resolution display.
- Gaia source context, separate WISE reference imagery and coordinate sharing.
- Animated landing story with accessible, reduced-motion and narrow-screen paths.

## Immediate hosting fix

Cancellation now sends `Content-Type: application/json` and an empty JSON object
with its POST request. This satisfies the Cloudflare gateway's JSON requirement
and prevents a valid cancellation from being rejected for missing content type.
A dedicated regression test checks the outgoing header and body.

## Hosting configuration

Set `NEXT_PUBLIC_API_BASE_URL` to the backend's public HTTPS origin before
building the frontend, and include the frontend origin in `KHONSU_CORS_ORIGINS`.
The frontend remains a static Next.js export.

Local Compose stores SQLite in the persistent `notebook-data` volume. The
existing Cloudflare Container configuration leaves database backup disabled
until durable server storage is configured; browser notes and export remain
available. There is no login or cross-device account synchronization. Export
before clearing browser storage, which holds the private notebook access key.

## Verification and scientific limits

All 110 frontend logic tests pass, including the cancellation regression. The
integrated feature pass also passed 152 API/science tests, eight gateway tests,
Chrome/Firefox console and notebook acceptance, and actual Docker database
persistence across API-container recreation. See the
[acceptance record](../guided-notebook.md) for methods and limitations.

Display estimates are labelled visual guesses, not recovered measurements.
Larger rendering sizes do not create new telescope resolution. Candidate notes
are human observations for follow-up, not confirmed discoveries. Cached examples
retain their real-data provenance; live coverage and archive availability vary.
